# ON-DEM-WG1 Rotating drum benchmarking

This repo brings together all the required scripts to process the datasets generated by various open- and closed-source particle simulation codes participating in the ON-DEM-WG1 benchmarking cases
- [Bi-disperse spheres](https://on-dem.atlassian.net/wiki/spaces/Index/pages/265420813/D1+Spheres?atlOrigin=eyJpIjoiODkyNTg3MzkwNTQ0NGYzOTkwNjg4NGJlMzUyZmYwOTUiLCJwIjoiYyJ9)
- [Bi-disperse cubes](https://on-dem.atlassian.net/wiki/spaces/Index/pages/265191445/D2+Cubes?atlOrigin=eyJpIjoiYmM2Y2Y5Mjk1MmQ3NGNhNGIyYzMwNTZkN2YyNzg2ZGQiLCJwIjoiYyJ9)

The corresponding datasets and early stage results can be found [here on Zenodo](https://doi.org/10.5281/zenodo.21641256)
